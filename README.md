HR Analytics – Predict Employee Attrition

Project Overview

This project analyzes employee data to understand employee attrition. It displays employee details, calculates the attrition rate, and visualizes employees who left or stayed.

Objective

- Analyze employee attrition.
- Calculate the attrition rate.
- Display employee salary and experience.
- Visualize attrition using a bar chart.

Technologies Used

- Python
- Matplotlib

Features

- Displays employee details.
- Calculates total employees and employees who left.
- Calculates the attrition percentage.
- Generates an Employee Attrition Analysis graph.

How to Run

1. Install Pydroid 3.
2. Install Matplotlib.
3. Copy the Python code into a file named "hr.py".
4. Click the Run button.
5. View the output and graph.

Sample Dataset

The project uses sample data containing employee salary, years of experience, overtime, and attrition status.

Output

- Employee details
- Total number of employees
- Number of employees who left
- Attrition rate
- Employee attrition bar chart

Conclusion

This mini project demonstrates basic employee data analysis and visualization using Python. It uses sample data for educational purposes.
